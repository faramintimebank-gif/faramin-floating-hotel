# وب‌سایت هتل شناور فرامین — بسته آماده جایگزینی

این بسته شامل چهار فایل است:
- `index.html` — ساختار و محتوای فارسی/انگلیسی صفحه
- `style.css` — ظاهر، رنگ‌ها و واکنش‌گرایی
- `script.js` — رفتارهای سمت مرورگر از جمله تغییر زبان و منو
- `README-FA.md` — راهنمای فارسی

## نصب در مخزن موجود
1. از مخزن فعلی نسخه پشتیبان بگیرید.
2. این چهار فایل را در همان پوشه‌ای قرار دهید که `index.html` فعلی قرار دارد؛ فایل‌های هم‌نام را جایگزین کنید.
3. تغییرات را با دسترسی مجاز در مخزن فعلی ثبت و بارگذاری کنید.
4. پس از اجرای GitHub Pages، سایت را در پنجره ناشناس باز کنید و منو، تغییر زبان، لینک‌های تماس و نمایش موبایل را بررسی کنید.

## وضعیت قابلیت‌ها
طرح‌های هتل زیرآبی، مارینا، شهرک چندمنظوره، زیرساخت آب و انرژی و توسعه گردشگری، چشم‌اندازهای مفهومی هستند و نباید به‌عنوان پروژه ساخته‌شده یا دارای مجوز قطعی معرفی شوند. ثبت‌نام، پروفایل اعضا، جست‌وجوی خدمات، پیام‌رسانی، رزرو و ثبت تراکنش UALL تا زمان پیاده‌سازی و آزمون واقعی فعال محسوب نمی‌شوند.

قاعده پیشنهادی بانک زمان: هر یک ساعت خدمت تأییدشده برابر با یک UALL است؛ ثبت واقعی مبادله نیازمند سازوکار قابل پیگیری و تأیید طرفین است.

## انتشار و آزمون
این بسته به‌خودی‌خود مخزن GitHub را تغییر نمی‌دهد و انتشار سایت را انجام نمی‌دهد. پس از جایگزینی فایل‌ها، نسخه منتشرشده را در موبایل و دسکتاپ آزمایش کنید. بررسی ZIP تنها سلامت بسته و فایل‌ها را تأیید می‌کند، نه انتشار آنلاین را.
