# وب‌سایت هتل شناور فرامین — نسخه ایستا

## فایل‌ها
- `index.html`: محتوای سایت
- `style.css`: طراحی واکنش‌گرا
- `script.js`: تغییر زبان و سال جاری

## انتشار رایگان در GitHub Pages
1. وارد حساب GitHub خود شوید و یک مخزن **Public** جدید بسازید؛ نام پیشنهادی: `faramin-floating-hotel`.
2. فایل‌های این بسته را در ریشه مخزن بارگذاری کنید؛ `index.html` باید در ریشه باشد.
3. در مخزن به **Settings → Pages** بروید.
4. در بخش Build and deployment، گزینه **Deploy from a branch** را انتخاب کنید.
5. شاخه `main` و پوشه `/(root)` را انتخاب و ذخیره کنید.
6. پس از پایان انتشار، نشانی نشان‌داده‌شده در همان صفحه را باز کنید.

## پیش از انتشار عمومی
- در `index.html` عبارت `REPLACE_WITH_OFFICIAL_EMAIL` را با ایمیل رسمی جایگزین کنید؛ یا اگر ایمیل عمومی ندارید، دکمه تماس را حذف کنید.
- اطلاعات تماس، مالکیت، محل اجرا، مجوزها، ارقام مالی و نام همکاران را فقط پس از تأیید درج کنید.
- این نسخه فرم ارسال اطلاعات ندارد و هیچ پایگاه داده یا درگاه پرداختی را متصل نمی‌کند.
- سایت از Google Fonts برای فونت Vazirmatn استفاده می‌کند؛ برای حذف این وابستگی، فونت را با رعایت مجوز در خود مخزن میزبانی کنید یا فونت سیستمی را به کار ببرید.
- قبل از بارگذاری، مطمئن شوید هیچ اطلاعات محرمانه‌ای در فایل‌ها نیست.

## دامنه
GitHub Pages یک نشانی رایگان از نوع `USERNAME.github.io/REPOSITORY` می‌دهد. دامنه اختصاصی معمولاً نیاز به خرید دارد؛ برای شروع ضرورتی ندارد.

این بسته یک نمونه اولیه قابل انتشار است؛ انتشار روی حساب کاربر، تأیید مالکیت دامنه یا انجام بررسی حقوقی و فنی بیرونی در این بسته انجام نشده است.
